# Lantern

LAN web interface discovery dashboard.

![Screenshot](./assets/lantern.png)

## Features
- Scan LAN
- Detect web interfaces
- Simple dashboard

## Run
```bash
docker build -t lantern .
docker run -p 8000:8000 lantern
```
